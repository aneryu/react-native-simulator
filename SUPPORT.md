# Support

React Native Simulator is an experimental, community-supported project. There
is no guaranteed response time or support-level agreement.

## Before asking for help

1. Run `rnsim --version` and `rnsim doctor --json`.
2. Read the [getting started guide](docs/guides/GETTING_STARTED.md) and
   [troubleshooting guide](docs/guides/TROUBLESHOOTING.md).
3. Check the [RN 0.87 capability baseline](docs/baselines/RN087_CAPABILITY_BASELINE.md).
4. Confirm that your bundle targets the pinned React Native and Hermes versions.

## Where to ask

- Use the support question issue form for installation, configuration, and
  expected-behavior questions.
- Use the bug report form for reproducible defects.
- Use the capability request form for missing modules, components, events, or
  platform contracts.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; do not disclose them
  in a public issue.

Include the exact command, sanitized `rnsim.json`, bundle build mode, complete
error output, and relevant screenshot, metrics JSON, or trace. State whether
the result came from a source build, installed runtime, or release archive.
