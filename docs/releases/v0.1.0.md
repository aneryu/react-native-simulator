# React Native Simulator v0.1.0

This is the first experimental macOS arm64 release of React Native Simulator.
It runs caller-built React Native applications directly on macOS through the
same Hermes, ReactInstance, RuntimeScheduler, Fabric, Yoga, retained-scene, and
Skia engine used by its interactive and headless modes. Public conformance is
disabled until canonical profile/font/oracle manifests exist.

## Install the runtime and optional RN Tester demo

Download each desired asset with its adjacent `.sha256` file:

```sh
shasum -a 256 -c rnsim-v0.1.0-macos-arm64.tar.gz.sha256
tar xf rnsim-v0.1.0-macos-arm64.tar.gz
./rnsim/install.sh

shasum -a 256 -c rnsim-rntester-demo-v0.1.0-macos-arm64.tar.gz.sha256
tar xf rnsim-rntester-demo-v0.1.0-macos-arm64.tar.gz
xattr -dr com.apple.quarantine rnsim-rntester-demo
rnsim --config rnsim-rntester-demo/rnsim.json
```

The runtime installer copies a stable self-contained tree below `~/.local` and
links the CLI into `~/.local/bin`. The RN Tester package owns its relative
configuration and application addon. Neither runtime path requires a React
Native checkout, Node.js, npm, or Homebrew.

## Scope

- React Native 0.87.0 and Hermes v1 `260318099.0.1` are pinned.
- Android is the first certification profile.
- Interactive and headless frontends share one semantic engine; public
  conformance commands fail closed in this release.
- The optional RN Tester support asset is precompiled to bytecode by the exact
  runtime Hermes revision and records release/RN/Hermes/addon compatibility in
  `manifest.json`.
- The runtime archive includes the RN 0.87 DevTools web frontend. The compact
  RN Tester support archive still uses host macOS font fallback, so Android
  typography and pixel certification require caller-supplied fonts.
- Folly is linked statically, avoiding Homebrew's unused Boost.Regex/ICU
  dependency chain. Skia keeps ICU static and transitionally reuses its pinned
  Flutter-desktop text data filter; no Flutter runtime is linked. The engine
  exports only its embedding API and versioned addon ABI symbols.
  Byte-identical RN Tester fixtures share archive storage while retaining all
  original asset paths and bytes.
- The release is experimental and does not claim complete Android or iOS
  equivalence. Consult `docs/baselines/RN087_CAPABILITY_BASELINE.md` for exact
  implemented, adapted, mocked, and unavailable behavior.
- Every packaged Mach-O is ad-hoc signed after relocation and stripping. The
  assets are not Developer ID signed or notarized, so checksum verification and
  explicit quarantine removal remain required trust steps.

## Verification

Release verification covers both native presets, runtime/addon isolation,
relocatable Mach-O dependencies and signatures, installation from a fresh
directory, RN Tester startup with the two assets placed under unrelated parent
directories, and a real interactive Skia frame. The release workflow also
packages each archive twice and requires byte-identical output.
